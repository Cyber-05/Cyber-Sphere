## 🖥️ Kali Linux & Security Tools Overview

### Kali Linux - The Industry Standard

**Kali Linux** is a Debian-based Linux distribution purpose-built for penetration testing and ethical hacking. It's the de facto standard in the cybersecurity industry and is featured prominently in Cyber-Sphere.

#### What is Kali Linux?
Kali Linux is maintained by Offensive Security and comes pre-loaded with 600+ penetration testing and security auditing tools. It's designed for:
- **Penetration Testers**: Authorized security testing of systems
- **Security Researchers**: Vulnerability research and analysis
- **Red Team Operators**: Simulating real-world attacks
- **Ethical Hackers**: Finding and fixing security weaknesses
- **Students**: Learning cybersecurity hands-on

#### Key Features of Kali Linux
- **Pre-installed Tools**: 600+ hacking and security tools out of the box
- **Free & Open Source**: Licensed under GPL
- **Multiple Desktop Environments**: GNOME, KDE, Xfce, i3
- **Customizable**: Tailor the distro to your needs
- **Community Support**: Active forums and documentation
- **Regular Updates**: New tools and updates every few months
- **Live Boot Capability**: Run from USB without installation
- **Professional Documentation**: Comprehensive guides and tutorials

### Other Essential Security Platforms & Tools

#### **Metasploit Framework**
The most widely used penetration testing framework globally.
- **Thousands of Exploits**: Pre-built exploit modules
- **Payload Generation**: Create custom shells and backdoors
- **Post-Exploitation**: Maintain access and extract data
- **Vulnerability Database**: Up-to-date vulnerability information
- **Community Modules**: Contributions from security researchers

#### **Burp Suite**
Industry leader for web application security testing.
- **Professional Edition**: Full-featured penetration testing
- **Community Edition**: Free version with core features
- **Scanner**: Automated vulnerability detection
- **Intruder**: Automated attacks and fuzzing
- **Repeater**: Manual request modification and testing

#### **OWASP Top 10**
The most critical web application security risks:
1. **Injection** - SQL, OS, LDAP injection attacks
2. **Broken Authentication** - Session management flaws
3. **Sensitive Data Exposure** - Unencrypted sensitive information
4. **XML External Entities (XXE)** - XML processing vulnerabilities
5. **Broken Access Control** - Insufficient authorization
6. **Security Misconfiguration** - Weak security settings
7. **Cross-Site Scripting (XSS)** - Injected malicious scripts
8. **Insecure Deserialization** - Unsafe object serialization
9. **Using Components with Known Vulnerabilities** - Outdated dependencies
10. **Insufficient Logging & Monitoring** - Weak audit trails

- **React 18** - Modern UI framework with hooks and concurrent features

- **Supabase** - Open-source Firebase alternative with PostgreSQL

### DevOps & Deployment

## 📦 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

```bash
git clone https://github.com/Cyber-05/Cyber-Sphere.git
cd Cyber-Sphere
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
