# Cyber-Sphere 🌍

A cybersecurity-focused web platform with an interactive 3D Earth visualization that responds to mouse movement.

## 🌐 Live Demo

**[Visit Cyber-Sphere Live](https://cyber-sphere-2el90vnlt-cyber-05s-projects.vercel.app)**

## ✨ Features

- **Interactive 3D Earth**: Mouse-responsive earth rotation with realistic textures
- **Academy Section**: Cybersecurity learning resources
- **Career Center**: Job opportunities and career guidance
- **Knowledge Library**: Comprehensive security documentation
- **Learning Platforms**: Access to educational content
- **Community Section**: Connect with security professionals
- **News Dashboard**: Latest cybersecurity news and updates
- **Tools Explorer**: Directory of security tools
- **Global Cyber Map**: Real-time cyber threat visualization

## 🎨 Technologies Used

- **React 18** - UI Framework
- **TypeScript** - Type-safe JavaScript
- **Three.js** - 3D graphics
- **Tailwind CSS** - Styling
- **Vite** - Build tool
- **Framer Motion** - Animations
- **Supabase** - Backend services

## 🚀 Deployment

Deployed and hosted on **Vercel** for free, with automatic updates on every push to GitHub.

Live URL: `https://cyber-sphere-2el90vnlt-cyber-05s-projects.vercel.app`

## 📦 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

```bash
git clone https://github.com/Cyber-05/Cyber-Sphere.git
cd Cyber-Sphere
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## 🎯 Mouse Interaction

Move your mouse across the screen to see the Earth respond and rotate in real-time! The interactive 3D visualization creates an immersive experience.
